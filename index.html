PERSONAL WINDOWS BOOK ASSISTANT

把电子书送回自己的收件箱。

BookBot 是运行在个人 Windows 电脑上的电子书助手。它读取自己发送的书籍指令，调用本机电子书工具查找和下载内容，再归档到本地并把结果发回同一邮箱。

个人部署 · 自己的邮箱 · 有权获取的内容
Gmail 指令→ Windows BookBot→ 本地书库与邮件附件

怎样使用

  1. 在自己的电脑上安装、配置 BookBot，并授权自己的 Gmail。
  2. 给自己发送标题为 [BOOKBOT] 的指令邮件，说明书名、作者、语言和格式。也可让已连接 Gmail 的聊天助手按要求发出指令。
  3. BookBot 检查匹配结果。多个版本相近时，先回复候选清单，等待选择。
  4. 下载文件通过基础格式校验后归档；符合附件大小限制的文件随回信送达。

为什么需要 Gmail 权限

读取权限用于查找并解析指令邮件；发送权限用于把候选版本、处理状态和附件回复给自己。Google 授予的读取权限覆盖邮箱，程序按标题、时间、发件人、收件人及邮箱标签筛选符合条件的指令。

授权后，凭据加密保存在该 Windows 用户的本机目录。具体处理范围、保留方式和撤销步骤见隐私政策。

这份网站的用途

本网站提供应用说明和隐私信息，不提供邮箱登录入口或电子书下载。实际邮件与书籍处理发生在用户自己的 Windows 电脑上；电脑须开机、联网并运行 BookBot。

仅供部署者本人使用。书籍来源、授权范围和可下载状态由实际来源决定。
